SoundTrip 실행 안내 (수업 범위 버전)

1. 폴더 전체를 VS Code로 열고 Live Server로 11_노래트송_index.html 실행
   (fetch를 쓰기 때문에 파일을 더블클릭하면 데이터가 안 불러와져요)
2. 폰트(Noto Sans KR)는 구글 폰트 링크라 인터넷 연결이 필요해요.

[파일]
- HTML 11개 / style.css / player.css / app.js / player.js / data.json
- 메뉴, 단계, 푸터, 도시, 장르, 곡, 추천 옵션은 전부 data.json에서 fetch로 가져와 그려요.
  -> 도시/장르/곡 추가는 data.json만 고치면 돼요.
  곡 추가 시 필요한 값: id, title, artist, playlist("도시-장르"), genre, rank, tags, audio(재생 가능한 곡만)

[저장소 구분]
- sessionStorage (이번 방문, 탭마다 독립): 고른 도시/게이트/장르, 로그인 상태, 추천 선택 조건
- localStorage (영구): 프로필, 좋아요, 담은 곡/플레이리스트, 도착 스탬프, 들은 곡, 최근 조건

[수업 기능]
- fetch + JSON / XMLHttpRequest(상단 공지) / addEventListener / Web Storage
